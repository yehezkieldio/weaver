# Academic Research RAG - Output Data & IMRAD Writing Guide

This document lists all the scientific data outputs generated by this project and provides a guide on how to report them in an academic paper following the IMRAD (Introduction, Methods, Results, and Discussion) structure.

---

## Part 1: Output Data Inventory

### 1. Evaluation Metrics
These metrics are calculated for every question in an evaluation run and stored in the database.

#### A. Quality Metrics (RAGAS & Derived)
*   **Faithfulness (`faithfulness`):** Measures if the answer is derived *only* from the context. (0.0 - 1.0)
*   **Answer Relevancy (`answerRelevancy`):** Measures if the answer actually addresses the user's question. (0.0 - 1.0)
*   **Answer Correctness (`answerCorrectness`):** Semantic similarity and factual agreement with the "Ground Truth" answer. (0.0 - 1.0)

#### B. Retrieval Metrics
*   **Context Precision (`contextPrecision`):** The proportion of relevant chunks in the retrieved context. (0.0 - 1.0)
*   **Context Recall (`contextRecall`):** The proportion of ground truth facts found in the retrieved context. (0.0 - 1.0)
*   **Context Relevancy (`contextRelevancy`):** How much of the retrieved context is actually needed to answer the question. (0.0 - 1.0)
*   **NDCG (Normalized Discounted Cumulative Gain):** Measures ranking quality of retrieved documents. (0.0 - 1.0)
*   **MRR (Mean Reciprocal Rank):** Measures how high the first relevant document appears. (0.0 - 1.0)

#### C. Domain-Specific Metrics
*   **Hallucination Rate (`hallucinationRate`):** Frequency of generated information not supported by context. (0.0 - 1.0, Lower is better)
*   **Citation Accuracy (`citationAccuracy`):** Rate of correctly verified citations against source documents. (0.0 - 1.0)

#### D. Efficiency & Latency Metrics
*   **Total Latency (`latencyMs`):** End-to-end response time.
*   **Retrieval Latency:** Time taken to search the vector store.
*   **Reranking Latency:** Time taken by the reranker model.
*   **Agent Planning/Reasoning/Synthesis:** Time taken by specific cognitive steps (for Agentic workflows).
*   **Agent Steps Used (`agentStepsUsed`):** Complexity measure of the agent's reasoning path.

### 2. Statistical Analyses
The `scripts/run-statistical-analysis.ts` script performs rigorous testing on the metrics.

#### A. Descriptive Statistics
*   N (Sample size)
*   Mean, Median
*   Standard Deviation (SD)
*   Standard Error of the Mean (SEM)
*   Skewness & Kurtosis (Distribution shape)
*   95% Confidence Intervals (Standard & Bootstrap)

#### B. Comparative Analysis (RAG vs. Non-RAG)
Used to prove the baseline effectiveness of the system.
*   **Hypothesis Tests:** Paired T-Test (parametric) or Wilcoxon Signed-Rank Test (non-parametric), automatically selected based on normality checks.
*   **Effect Size:** Cohen's *d* (magnitude of improvement).
*   **Assumption Checks:** Shapiro-Wilk (Normality), Levene's Test (Homogeneity of Variance).

#### C. Ablation Study Analysis
Used to compare different configurations (e.g., "Naive RAG" vs. "Hybrid Search" vs. "Agentic RAG").
*   **One-Way ANOVA:** To detect if *any* configuration is significantly different.
*   **Post-Hoc Tests:** Pairwise comparisons to identify *which* specific configurations differ.
*   **Ranking:** Configurations ranked by Faithfulness and Correctness with Confidence Intervals.

### 3. Data Visualization
Available in the Frontend Dashboard (`/evaluation`).

*   **Radar Charts:** For comparing multivariate performance (e.g., Faithfulness vs. Relevance vs. Latency) of different models.
*   **Bar/Line Charts:** For metric distributions and trends.
*   **Correlation Matrix:** Heatmap showing relationships between metrics (e.g., "Does higher Latency correlate with higher Faithfulness?").
*   **Scatter Plots:** Latency vs. Score distributions.

## Part 2: IMRAD Writing Guide

### 1. Introduction
*   **What to write:** Briefly mention that you evaluated the system using a comprehensive suite of metrics ranging from standard RAGAS scores to domain-specific academic constraints.
*   **Key phrase:** "We employed a multi-dimensional evaluation framework assessing retrieval quality, generation faithfulness, and citation accuracy."

### 2. Methods (Experimental Setup)
*   **Dataset:** Describe the "Ground Truth" dataset (size, source documents).
*   **Metrics Definition:** Briefly define the metrics used (refer to Part 1.1).
    *   *Example:* "Faithfulness was measured using the RAGAS framework, quantifying the extent to which claims were supported by retrieved context."
*   **Statistical Protocol:** Explicitly state the tests used from `statistical-analysis.ts`.
    *   *Example:* "We performed paired t-tests to compare RAG vs. Non-RAG baselines. For ablation studies, we used One-Way ANOVA with post-hoc analysis. All tests included normality checks (Shapiro-Wilk) and reported 95% Confidence Intervals."

### 3. Results
This is where you paste the outputs from the script and dashboard.

#### Subsection 3.1: Baseline Performance (RAG vs. Non-RAG)
*   **Visual:** Table comparing Mean scores with SD/SEM.
*   **Text:** "The RAG system demonstrated a statistically significant improvement over the Non-RAG baseline in Answer Relevancy (t(49) = 5.23, p < .001, Cohen's d = 1.2)."
*   **Key Data:** Use the "Comparative Analysis" output from the CLI script.

#### Subsection 3.2: Component Analysis (Ablation Study)
*   **Visual:** Radar Chart (from Dashboard) overlaying different configurations.
*   **Text:** "Ablation results indicate that Hybrid Search significantly outperformed Naive Retrieval (p < .05), particularly in Context Recall."
*   **Key Data:** Use the "Ranking" and "ANOVA" tables from the CLI script.

#### Subsection 3.3: Efficiency vs. Quality Trade-off
*   **Visual:** Scatter plot (Latency vs. Correctness).
*   **Text:** "While the Agentic workflow achieved the highest Accuracy (0.92), it incurred a 3x latency penalty compared to standard RAG (Mean: 4500ms vs 1500ms)."
*   **Key Data:** Use the "Latency Analysis" section from the CLI script.

### 4. Discussion
*   **Interpretation:** Explain *why* the numbers look that way.
    *   *Example:* "The high Hallucination Rate in the Naive configuration suggests that poor retrieval relevance forces the LLM to fabricate information."
*   **Correlations:** Use the Correlation Matrix.
    *   *Example:* "We observed a strong positive correlation (r=0.78) between Context Precision and Faithfulness, validating the hypothesis that better retrieval reduces hallucinations."
*   **Limitations:** Mention if sample size (N) was small or if the dataset had biases.

## How to Export Data for the Paper
1.  **Raw Data (CSV):** Go to `/evaluation/manage` -> "Export Data" to get the raw CSV for Appendix or external analysis (SPSS/Python).
2.  **Statistical Report:** Run `bun run scripts/run-statistical-analysis.ts --latest` and copy the ASCII tables directly.
3.  **Charts:** Take high-resolution screenshots of the `/evaluation` dashboard.
